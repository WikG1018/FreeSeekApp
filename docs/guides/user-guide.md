## 安装与更新

从 [FreeSeek 发行页](https://github.com/WikG1018/FreeSeekApp/releases/latest)下载与平台对应的文件。

| 平台 | 安装与使用 |
| --- | --- |
| Android | 下载 `freeseek-v…-release.apk`。从浏览器或文件管理器打开 APK，按系统提示授权安装。用同一签名的新版本覆盖安装可保留本地数据。 |
| Windows | 下载 `freeseek-v…-windows-x64-setup.exe` 并运行，再从开始菜单打开。安装包未做 Authenticode 签名，系统可能标为「未知发布者」。 |
| 桌面或手机浏览器 | 打开 [FreeSeek 网页版](https://wikg1018.github.io/FreeSeekApp/)。数据会随浏览器和站点地址分别保存。 |
| iPhone / iPad | 用 Safari 打开网页版，再按[添加到主屏幕的步骤](iphone-web-app.md)使用。 |

需要核对下载内容时，打开同一发行页的 `SHA256SUMS`，将对应文件名的摘要与本机计算结果对照。在 PowerShell 可运行 `Get-FileHash -Algorithm SHA256 -LiteralPath '你的安装包路径'`。

首次启动可先阅读「使用前须知」，再选择开始聊天或导入旧记录。安装版发现更新后会尝试提前下载。点侧边栏版本入口先看更新说明，下载及校验完成后由你确认安装。也可在「设置 → 关于 FreeSeek → 检查更新」手动检查。网页版收到新版本提示后，可在完成当前回复与保存操作后刷新。

## 连接模型

### DeepSeek 官方

1. 打开「设置 → API 服务」。按页首教程在 [DeepSeek 开放平台](https://platform.deepseek.com/)创建 API Key。
2. 将密钥填入 FreeSeek，点「验证并保存」。
3. 选择 `deepseek-flash`（Flash）或 `deepseek-v4-pro`（V4 Pro）。当前模型的输入能力会显示在模型旁边，发图片时选择支持图片输入的模型。

申请、充值与实际扣费由服务商处理。Flash 和 V4 Pro 的价格及图片能力不同。[DeepSeek 模型和定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) · [API 服务截图](../screenshots/current/android-api-service.png)

### 第三方服务或自建网关

1. 进入「API 服务 → 进阶 → 高级自定义配置」，添加连接。使用服务商预填时，按密钥来源选择按量 API 或订阅入口。两种入口可能有不同地址和密钥。
2. 核对协议、服务地址和密钥。支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini 等连接方式。基础地址保留服务要求的版本前缀。
3. 在这个连接下「获取模型」或手动输入准确的模型 ID。按模型配置上下文、最大输出、默认思考强度、图片和 PDF 输入能力。能力设置应与服务商文档一致。
4. 点「测试模型」确认可返回正文，再保存并选择用于聊天的模型。测试会发送一条短消息，可能消耗额度。

网页端的模型接口必须允许来自 FreeSeek 站点的跨域请求。使用自建服务时建议使用 HTTPS，明文 HTTP 会在网络上明文传输内容和密钥。

## 聊天搜索与长对话

### 对话操作

- 轻点顶栏标题回到对话开头，长按打开「对话助手」。修改提问或重新生成会保留可切换的消息版本。
- 在侧边栏输入关键词，匹配范围包括标题与当前可见分支的聊天正文。展开某个会话后可翻阅多条命中，点任意一条跳到对应消息。重新打开侧边栏时保留搜索词和结果页，切换回答版本后按新分支刷新。旧消息附近继续滑动会加载相邻历史，点「最新」回到末尾。
- 会话的更多菜单可置顶、重命名、接续或备份。侧边栏可按时间或会话类型分组，置顶会话集中显示。
- 在「设置 → 对话偏好」打开「显示模型切换」，可在输入框上方改选模型。再开启「显示思考强度选择」，可按模型支持的档位调整后续回复。

### 智能搜索和附件

- **Flash 普通对话**使用 DeepSeek 的服务端联网能力。
- **V4 Pro 和支持工具调用的第三方模型**可在「高级自定义配置 → 对话联网搜索」接入搜索服务。打开「智能搜索」后，模型决定何时查找，可按回答中的来源链接核对内容。独立搜索调用、网页内容进入模型后的 Token 用量按各自服务计费。
- 点「＋」选择文件、相册或拍照。图片和 PDF 能力取决于选中的模型及接口。文本与部分文档可在本机提取内容后发送。扫描件、图表或排版复杂的文件能读到多少，取决于解析方式。
- 在消息中打开图片，可双指缩放。在文件预览中可根据格式翻页、查找、缩放、保存或分享原件。

### 上下文满了怎么办

输入框上方的圆环显示当前模型请求的**预计上下文用量**，可展开查看历史、当前草稿和预留回复。Flash 和 V4 Pro 的官方窗口为 1M tokens。自定义模型以已知或配置的窗口为准。会话累计用量是历次请求的统计。[DeepSeek 模型规格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

在侧边栏会话菜单选「整理并压缩上下文」，可将早期对话整理成摘要继续使用。摘要覆盖已完成的早期聊天，本轮消息与附件会在压缩后用于当前请求。近期轮次、完整聊天原文和附件保存在本机。也可从「设置 → 对话偏好 → 长对话」开启「自动压缩上下文」，压缩会消耗当前模型的额度。

发生压缩拒绝时，已生成且可用的摘要会保留。若旧历史仍装不下，可选「用最近的聊天继续」发送本轮消息，并在之后从原会话的压缩菜单恢复完整上下文。正文单独或附件解析超限时，可缩小本轮提交的内容、分段发送，或换支持该输入的模型。

## 语音与角色配音

| 用法 | 入口 |
| --- | --- |
| 语音输入 | 点输入框中的麦克风，录制后转写。确认文字已填进草稿，再发送。 |
| 普通朗读 | 点回复旁的朗读按钮。可在「设置 → 对话偏好 → 朗读方式」选「普通朗读」和音色，需要 DeepSeek 官方 API Key。语音输入同样使用 DeepSeek 语音接口。 |
| 角色配音 | 在「设置 → 对话偏好 → 朗读方式」选「角色配音」，从同页进入「配音服务」。角色和旁白各用自己的音色。 |

配音服务可复用已保存的小米 MiMo 连接，也可单独配置。

1. 如果使用指引中的按量 API 密钥链接，选「按量 API」。订阅套餐生成的密钥选「Token Plan 订阅」。
2. 填写密钥，核对自动带出的服务地址。使用官方 MiMo 时，可留空预置音色和描述音色的模型名，使用界面显示的默认值。
3. 分别点「试听旁白」「试听主角」，确认服务和音色后保存。实际语音额度与费用以 [MiMo 定价](https://mimo.mi.com/docs/zh-CN/price/pay-as-you-go)及套餐规则为准。

有角色的聊天可点顶栏的角色按钮，查看、试听或编辑人物。主角可有多个，主角和有戏份的配角可按描述生成声音。角色资料中可以调整名字、别名、分量与性格。手动选定的音色优先。生成回复时可点「边生成边读」，开始后用同一处控制暂停、继续和停止。回复重生成后，朗读对应新的回答版本。

## 人设记忆与 Agent

- **人设**从「设置 → 人设与提示词」管理。可自建、复制、导入或导出，选择默认人设或用于某个聊天。
- **自动记忆**默认关闭。在「记忆与 Agent」开启后，应用会按对话自动整理长期偏好。相关记忆可能随消息发送给当前模型。在「最近记住了什么」可查看来源或撤销，长按对话标题可单独暂停当前会话的记忆。Windows 的设置入口叫「记忆（实验性功能）」。
- **Agent**是 Android 与网页端的实验功能。在「记忆与 Agent」开启「新建对话时选择模式」，新建时选 Agent。也可管理可复用的 Agent 和它们可用的工具。

| 模式 | 适合什么 |
| --- | --- |
| 任务 | 直接执行一轮明确的任务，例如整理附件或制作表格。 |
| 计划 | 先调研并给出步骤。可以要求修改，确认后再执行。 |
| 目标 | 按给出的完成标准推进，可查看执行进度、暂停或继续。 |

从输入框上方的状态展开计划与工具进度。在顶栏「成果」按对话轮次找文件，打开预览、保存或分享原件。搜索、公开网页、附件读取、计算、文件生成和项目工具可在「工具设置」管理。高级工具依赖支持工具调用的模型，网页端的联网、后台和文件能力取决于浏览器。Windows 版可查看从备份导入的 Agent 历史与成果。Android 的「对话偏好 → 后台与通知」可开启回复与任务完成通知，后台工作受通知权限和系统策略影响。

## 备份导入与恢复

**备份本机。** 进入「设置 → 数据管理 → 导出所有历史对话」，选择保存位置并确认 ZIP 的可用性。完整备份带有消息及分支、置顶、已保存的附件原件、会话用量、关联的人设和可用的任务成果。若有部分聊天或原件无法读取，界面会显示相应数量，仍可保存其余可用记录。

**从 DeepSeek 导入。** 在 DeepSeek 官方 App 的「设置 → 数据管理」导出对话，把 ZIP 保留原样带到 FreeSeek。在 FreeSeek 的「数据管理 → 导入历史对话」选文件，按提示检查并确认。

**从 FreeSeek 恢复。** 在同一入口选此前保存的 FreeSeek ZIP。新的会话加入现有列表，编号相同的会话可选「保留本机」或「使用备份」。同名但编号不同的会话会分别保留。重复项默认保留本机版本，校验失败或在提交前取消时保留本机原有记录。[重复项选择示例](../screenshots/current/android-backup-duplicates.png)

**大备份。** 导入支持符合格式要求的 ZIP64 归档。文件总大小与单条会话的解析上限分开计算，单条会话数据的读取上限为 256 MiB，还取决于结构和设备存储空间。导入前预留足够空间，文件很大时保持应用在前台。源备份缺失的附件原件需要重新选择。

API 密钥、服务地址、请求头和设备设置需在新设备上重新配置。备份文件的格式与读取限制见[归档说明](../../src/services/chat/history/README.md)。

## 用量费用与偏好

- **用量与费用**。在设置中看按日期、聊天和模型统计的 Token 与费用，按已报告缓存数据的输入计算缓存命中率。点回复的用量标签可查看该次请求明细。自定义模型可设置单价，费用以服务商实际账单为准。
- **使用时长**。在设置中查看本机使用记录和各会话的时长排行。
- **对话偏好**。可控制启动时恢复上次对话或打开新对话，设置输入框回车发送或换行、显示模型与用量。回车行为只适用于聊天输入框。
- **外观与语言**。可调整主题、字号、默认 MiSans 或系统字体，以及简体中文或英文。

## 数据去向

| 数据或行为 | 存放位置或去向 |
| --- | --- |
| 聊天、附件、人设、记忆、使用记录 | 当前应用或站点在本机的存储。通过 ZIP 备份迁移聊天。 |
| API Key、服务连接 | 本机设置。密钥用于相应模型或工具服务的鉴权。 |
| 发送的消息、所选附件和相关记忆 | 当前选用的模型服务。授权记忆后，关联内容可随请求发送。 |
| 智能搜索、打开网页、语音 | 配置的搜索、网页或语音服务。语音转写会上传要转写的录音。 |
| 检查更新 | GitHub 发行页或用于获取版本与附件的镜像。 |
| 诊断包 | 本机生成，由你选择保存位置或分享到指定应用。 |

换机时先导出并验证备份。卸载、清除应用数据、清除浏览器站点存储或更换浏览器配置可能让旧记录不再可读。

## 常见问题与诊断

| 遇到的问题 | 怎么处理 |
| --- | --- |
| 密钥已填，仍无法聊天 | 检查余额、额度和所用模型。第三方确认按量/订阅对应的地址和密钥，先用「测试模型」验证。网页版还需检查跨域设置。 |
| 图片或文档发送失败 | 确认当前模型支持相应输入。旧记录只有附件名称时，请从本机重新选原件。文件解析和模型窗口分别有限制，可试着提交本轮需要的页或片段。 |
| 长对话提示超限 | 先看错误内容与上下文详情，再选择压缩历史、使用最近聊天或拆分本轮附件。 |
| 侧边栏以前的记录暂时空白 | 按界面提示重试，让应用重新检查本机记录。现有应用数据与备份可用于恢复，先保存能读取的记录。 |
| 估算费用与账单有差异 | 检查所选模型价格、缓存数据和附加服务费用。服务商账单为最终依据。 |

反馈问题时在「设置 → 关于 FreeSeek」中使用「导出并分享诊断包」或「保存诊断包到文件」。同时说明 FreeSeek 版本、系统、发生时间、使用的功能和复现步骤。可在 [GitHub Issues](https://github.com/WikG1018/FreeSeekApp/issues)描述问题。

诊断包包含应用与设备环境、运行状态和脱敏日志。常规诊断包排除密钥、聊天和人设正文、附件原件及录音。日志按容量保留最近 7 天内的记录。启动异常页可保存启动诊断，完整打包失败时，Android 可提供基础诊断包。分享前可先检查 ZIP 内容。
