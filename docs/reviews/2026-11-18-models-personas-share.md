# 2.4.0 模型、人设、诊断分享与沉浸聊天验收

范围：Android / Web 共用客户端，继续覆盖 Android 10–17；iOS 不构建发布。延续回复末尾附件说明隐藏、Token/费用开关和旧 WebView 兼容。

## 功能与保护

- 移除 `viewport-fit=cover`，使用 `auto` 与 SystemBars native，避免 WebView 140+ 在加载后切换 passthrough 安全区导致顶栏移到状态栏。Appearance 原生插件只改窗口主题属性与底色，不重建 Activity；旋转后仍由 SystemBars 读取一致的主题底色。
- 中部单指右滑打开侧栏，左滑关闭；同一进度驱动抽屉、遮罩与主界面，拖动阶段不逐帧重绘 React。方向锁定前保留纵向滚动，排除输入、选择文本、横向滚动内容和弹层；取消、快速开合、Escape、减少动效均有处理。底部只保留设置/打赏，更新移到列表上方；置顶状态持久化、分组，官方/本机备份往返保留。
- 官方长记录改用流式 JSON 解析（固定 64KiB 解析片，适时让出主线程），避免 Blob/完整 JSON 字符串/对象三份并存。单条解压上限 128MiB、深度 64、词法单元 200 万；导出同预算，未去掉资源限制。继续校验整个流的尾部/CRC，再原子替换。导入确认、进度和失败呈现分开，进度可显示当前文件读取字节。
- 按用户提供的 ChatGPT 手机版参考调整聊天页：滚动内容铺满聊天区域，滚动层按实际顶栏/输入框高度渐变淡出，控件独立悬浮；闲置单行输入胶囊可展开完整工具。保留正文、复制与备份全文，测量输入框而非写死底部高度，阅读时展开草稿不跳位置，最后一条回复可完全滚到控件上方。大字号窄屏的工具按钮自动换行。
- 官方 API 可选 `deepseek-flash` / `deepseek-v4-pro`。Pro 图片请求在上传/生成前明确拒绝；估算区分 Flash 和 Pro，并按响应模型及每次续写用量保存计价依据，未知模型不冒用 Flash 价格。
- 高级配置支持多个服务、四种协议、URL/Key/模型、获取列表、短消息测试、输出参数、流式及可选图片/PDF、额外头与 JSON。保存失败不伪装成功；请求开始后固定当次配置，配置修订改变时原回答续写提示重新生成，避免无声改投其他服务。
- Android 原生 HTTP 按分片发送事件，最多四个未确认分片，支持断开取消、连接/读取时限、响应长度限制；不跟随重定向传递密钥。HTTP(S) 为用户主动配置地址，Android 17 的局域网权限单独处理。网页端遵守浏览器 CORS。
- 第三方附件不走 DeepSeek Files：文本/DOCX 本机解析，图片规范化后内联，PDF 按能力开关内联。缺原件、未开启对应能力、过大或不支持的文件明确拒绝，不默默丢附件；DeepSeek 专用工具、文件 ID 和语音不转交第三方。
- 模型切换按钮默认关闭，可在设置开启。第三方用量独立统计，未知价格不显示虚假的 Flash 费用。
- 关于页直接分享完整诊断，保存器仍可选；失败时可用原生基础诊断。共享 URI 仅授予接收方只读权限，缓存限定目录与保留范围；不自动发给联系人。Capacitor 参数日志关闭，独立结构化诊断仍保留脱敏信息。
- 人设库支持复制内置、搜索、编辑、追加导入、导出和应用当前会话；导入先全量校验再写入，保存失败保持旧内存状态并回滚偏好。既有长人设加载不因新的编辑限制而丢弃。正文预览限制长度，原文保留。
- 完整聊天备份写 v2 / 读 v1、v2，保留模型引用、响应模型与人设快照；API URL/Key/头不出现在备份或诊断，跨设备需重配服务。未知未来备份版本明确提示升级。

## 上下文问题

用户截图不能单独证明已用满 1M。上一轮显示用量与本轮完整请求不同，附件解析内容和输出额度也占窗口。原错误正则会把部分 `max_tokens` 参数错误归成上下文错误；已拆分两类提示，去掉跨模型固定“1M”的断言，诊断只从固定错误句式提取有限数值。

公开 DeepSeek 文档说明缓存自动管理，但 [Responses API](https://api-docs.deepseek.com/zh-cn/guides/responses_api/) 不支持 `context_management`/`truncation`，超窗口会返回 400。[上下文缓存](https://api-docs.deepseek.com/zh-cn/guides/kv_cache/) 不等于摘要压缩。本次未新增自动摘要；官方 App 是否另有内部摘要策略不作推断。

模型能力与价格依据：[Messages API](https://api-docs.deepseek.com/zh-cn/api/create-message/)、[模型元数据](https://api-docs.deepseek.com/zh-cn/api/list-models/)、[官方定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)；价格为本地估算，以服务账单为准。
