# FreeSeek 2.2.0 自审与验证

范围：Android 与共用网页代码。复查 2.0.6 上传失败恢复、1M 长上下文、更新镜像，并新增本机诊断日志；iOS 不调整。

## 已修复的问题

| 问题 | 修复与验证 |
| --- | --- |
| 401/402 上传失败无法在配置 Key 或充值后重试 | 保留原草稿与原文件，提供配置/充值入口和失败附件重试；真实 XHR 本地 HTTP 回归验证恢复 |
| 上传响应 200 却缺少文件 ID，卡片显示完成而不能发送 | 校验响应结构，协议错误明确显示并允许重试 |
| 上传与服务端处理共用等待响应头超时，大文件可能被误杀；响应体挂起无上限 | 进度驱动闲置计时、独立处理超时、响应读取超时、20 分钟总上限，支持取消，显示进度 |
| MIME 缺失的 BMP 未按图片处理；损坏图重复重试；超长边图片被接口拒绝 | 补齐图片扩展名识别、字节判断与转换；最长边压至 4096；串行解码；损坏或不可解码图片给明确原因 |
| 历史附件补传故障被静默省略 | 网络、鉴权、余额与服务器故障阻止发送并允许重试；不可读附件仅从当轮请求省略并提示，保留原消息和原件供备份 |
| 上千条历史消息及单条超长内容导致首屏明显卡顿 | 默认显示最近 40 条，可加载更早记录；超长正文折叠。请求、复制与备份仍使用全文；切换长分支保留版本选择器 |
| 只支持附件代理的镜像站被当成 GitHub API 代理 | 发布 API 与安装包源分开，新增独立 update.json 清单后备源；完整元数据读取限定时间与大小 |
| 离线或旧镜像元数据隐藏已经验证的缓存更新包；安装失败无反馈 | 恢复 ready/available 状态，安装失败提示重试，继续校验签名、包名、版本、摘要与长度 |
| 工具估算费用使用尝试次数 | 优先用 tool_search、tool_fetch、tool_image_search 成功计费数，旧归档保留兼容 |

## 诊断包

入口：设置 → 关于 FreeSeek → 诊断日志 → 导出诊断包。ZIP 包含 manifest.json、environment.json、summary.json、client-events.jsonl、native-events.jsonl、README.txt。

覆盖启动与前后台、在线/离线、客户端异常与资源加载失败、API 请求状态/耗时/请求关联 ID、上传进度和重试/取消、请求消息数量/体积/用量、存储故障、备份、更新下载/校验/安装、录音/转写/朗读、权限、字体缩放、原生/WebView 异常与进程退出原因。原生错误保留异常类型、有限栈帧及原因链。

独立日志库及原生私有目录，最多保留 7 天、客户端 2000 条与原生 1000 条；日志写入失败时导出内存记录。Android 使用已有分片系统保存器，取消与失败可恢复。不自动上传；不打包 API Key、正文、人设、标题、附件名称/原件、音频、转写、唯一设备标识或整份 logcat。导出时再次脱敏。

模拟器启动检查曾发现新观察器在 Bridge 创建前调用造成崩溃；已将其移至 super.onCreate 后并保留无 WebView 时的框架降级页。两次测试崩溃被诊断日志跨重启保留；修正后冷启动、系统保存和取消均通过。

- Android release 构建及现有 testDebugUnitTest 任务通过；现有原生单测仅模板用例，功能性证据来自浏览器和模拟器验收。

## 1M 与镜像边界

核对 [官方模型规格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 和 [Messages API](https://api-docs.deepseek.com/zh-cn/api/create-message/)：deepseek-flash 上下文为 1M token，输入与输出合计占用窗口。客户端不按显示分页截断请求，也不擅自降低模型窗口。

使用官方 V4 tokenizer 验证测试文本共 1,000,000 文本 token。在 Chromium 4 倍 CPU 降速下：单轮长文本请求 2,000,126 字节，完整保留；1000 轮/2000 条历史组装 2001 条请求消息，2,088,038 字节。首屏渲染从约 4.96 秒降至约 0.28–0.43 秒，DOM 节点从 32063 降至 724。单轮超长文本显示从约 4.09 秒降至约 0.10 秒。结果是本地边界与显示性能验证，不代表真实付费 API 接受满窗口请求；系统提示与输出还需占用窗口。

本机当日完整 GET：GitHub 直连、gh-proxy、ghfast、ghproxy.net 均拿到完整 2.1.0 APK，长度与 SHA-256 一致；ghfast 和 ghproxy.net 的 GitHub API 代理返回 403，因此仅作为附件/独立清单源。镜像可用性随网络与站点变化，不能保证所有运营商或未来时间均可达。
