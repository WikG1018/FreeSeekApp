# FreeSeek 2.6.1 输入区与附件菜单验收

安卓正式包名为 `app.freeseek.chat`，版本码 37。标签对应源码 `fab84c4fb9924903e52e1a4364d11ec13eb5586d`。APK 为 21,298,631 字节，SHA-256 为 `f58129744d33ad7eaec027bab7606b88f8082841e5a0a586f7fd595920247e29`，与 2.6.0 使用相同签名证书。[发布页](https://github.com/WikG1018/FreeSeekApp/releases/tag/v2.6.1)

- 浅色、深色下，正文经过模型行时减淡，并一直延伸到屏幕底边。对比黑白两种消息背景采样，胶囊内保持相同颜色，胶囊外保留递减的消息背景。测试覆盖单行、多行、125% 字号以及横屏短视口。抽屉底部左侧为打赏，右侧为设置齿轮，可用 Tab 按画面顺序操作。[查看滚动实录](https://github.com/WikG1018/FreeSeekApp/blob/26aa1beb902f661b478a8fb960233a845aa2b086/docs/screenshots/floating-dock-v2.6.1.mp4)
- Android 17 模拟器上，2.6.0 正式包在打开附件菜单时收起输入法，加号上边缘从 882 移到 1432 个物理像素。在同一设备上覆盖安装 2.6.1 后，加号保持在原位，系统输入法持续显示。Android 10 和 17 的竖屏、横屏都验证了打开、收起菜单和保留草稿。Android 17 另验证了进入系统文件选择器并取消返回。[查看系统键盘实录](https://github.com/WikG1018/FreeSeekApp/blob/26aa1beb902f661b478a8fb960233a845aa2b086/docs/screenshots/attachment-keyboard-v2.6.1.mp4)
- 本地类型、lint、4 项 smoke、106 项浏览器回归、旧 WebView 语法检查及 Android Release 构建和 lint 均已通过。两个模拟器读回的签名 APK 与发布文件摘要一致。

- 公开构建通过 106 项浏览器回归。首轮侧边栏坐标断言在抽屉移动时分两帧读取两个按钮，复核后改为同帧测量。通过构建的提交 `0afd5f5b592940dc7c9db547147a2cb39287ad06` 与标签仅相差这项测试修正，应用源码和构建配置一致。[公开构建](https://github.com/WikG1018/FreeSeekApp/actions/runs/44243450540)
- 发布标签的 Android 10–17 兼容矩阵八个系统镜像全部通过。运行设备均为模拟器，开发仓库的独立构建受 GitHub 账户付款或支出额度限制。[兼容矩阵](https://github.com/WikG1018/FreeSeekApp/actions/runs/44242720711)
- 发布后，GitHub 直连、ghfast.top、gh-proxy.com 与 ghproxy.net 的最新更新清单均指向 2.6.1。四个入口完整下载的 APK 均通过长度和 SHA-256 校验。
