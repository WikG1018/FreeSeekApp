# FreeSeek 2.6.0 安卓发布验收

2026 年 11 月 18 日发布。正式包名为 `app.freeseek.chat`，版本码 36，源码标签指向 `c5172be89a9dbf99aa7b0e01df585f1c5a1ab8df`。APK 大小为 21,298,999 字节，SHA-256 为 `bab73bfc72e7b0958355c3e703dd46967f82fb3bc3fefc1cfca595b1285e692f`，签名证书与已发布的 2.5.0 一致。[正式发布页](https://github.com/WikG1018/FreeSeekApp/releases/tag/v2.6.0)

## 界面与更新

- 侧边栏底部同排显示设置齿轮和打赏按钮。设置保留读屏名称及独立触控区域。人设库和长提示词编辑由设置页面统一滚动，人设的复制、应用、编辑和删除从各项右侧进入。
- 旧输入区在 360 × 720 的测试窗口中，模型行中心处的消息遮罩仍保留约 58% 不透明度。新版在整个输入区上方完成渐隐。像素回归覆盖单行、多行、窄屏、横屏和字号变化。
- 有更新时，版本提示位于「开启新对话」下方、历史列表上方。点开先看更新内容，随后选择下载或安装。下载途中可以关闭说明，重新点入仍显示进度。「关于 FreeSeek」随包提供本版本更新内容。图中的 v2.6.1 用于演示将来发现新版时的界面。[查看更新界面示例](../screenshots/update-sidebar-v2.6.png)

## 验证结果

- 本地及公开构建通过类型、lint、旧 WebView 语法、4 项 smoke 和 105 项浏览器回归。Android Release 构建与 lint 完成，原生 lint 为 0 个错误、20 个警告。[公开构建](https://github.com/WikG1018/FreeSeekApp/actions/runs/44237779060)
- 公开兼容矩阵覆盖 Android 10 至 17 的八个系统镜像，每个镜像通过三项原生检查。Android 10 / WebView 74 的全新环境安装了签名正式包，验证了同排齿轮、打赏入口和随包说明。[兼容测试矩阵](https://github.com/WikG1018/FreeSeekApp/actions/runs/44237780642)
- Android 17 模拟器从公开 2.5.0 正式 APK 原地升级，读回已安装 APK 的摘要与发布文件一致。升级前的提问、回答、附件引用、未发送草稿、置顶和自定义默认人设均可读取。运行设备为模拟器，厂商真机体验待现场确认。
- 发布后分别从 GitHub 直连、ghfast.top、gh-proxy.com 和 ghproxy.net 读取最新更新清单并下载完整 APK。四个入口返回的清单一致，安装包的长度与 SHA-256 均与签名发布文件相符。
- 开发仓库的独立 Actions 任务因 GitHub 账户付款或支出额度限制未启动。公开仓库在相同源码提交完成构建与兼容测试，两处发布使用相同的签名包和更新清单。
