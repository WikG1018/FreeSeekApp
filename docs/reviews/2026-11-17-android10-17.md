# Android 10–17 兼容与稳定性自审

范围：共用网页、Android 原生桥接、启动、聊天与长上下文、附件、备份导入/导出、语音、更新及诊断。iOS 不调整。延续用户要求：隐藏回复末尾附件说明，Token/费用显示由设置控制。

## 修复项

1. 取消上传后同 ID 重试可能复用已取消 Promise，旧 finally/catch 还可能移除新任务。现在按任务实例归属更新状态，队列取消立即移除并拒绝，取消原因兼容旧 WebView。
2. SSE 在信号已经取消时仍可能等待；已取消流立即关闭并返回 AbortError。历史附件准备释放 abort 监听，Key 验证后释放未使用响应体。
3. 图片解码没有时限，无法完成的解码会阻塞串行队列；增加 30 秒看门狗、取消清理和迟到 bitmap 释放。超过一亿像素的图片先拒绝，最长边继续压至 4096。
4. TTS 会将整个长音频排入内存；改为最多领先约 5 秒、每段最多 1 秒，完成后释放节点。初始化错误有提示；进入后台停止录音/朗读，释放麦克风，适配 Android 17 后台音频限制。
5. 文字草稿此前仅在内存，系统回收进程会丢失；本机持久化并在隐藏时刷新，发送/删除/替换历史后同步清理。未发送附件依然只在当前进程，不宣称附件草稿已持久化。
6. 归档 JSON 的声明长度未作内存准入限制；一次性 JSON 解析上限 32MiB，在读取前拒绝，原数据由暂存事务保护。完整备份导出同样遵循该上限，附件仍流式分块读取。
7. 原生文件保存并发窗口和失败清理不够完整；防重复打开、检查有限整数长度、创建/写入/结束失败清除临时文档。完整诊断已经生成后若保存失败，不再重复弹出另一保存窗口。
8. 更新下载增加原生单任务保护、立即断开取消连接，并在校验/发布前再次检查取消。
9. 实际 Android 17 横屏软键盘复查发现宽屏布局未正确避让，发送按钮被遮挡；视觉视口同步覆盖全部宽度，低高度聚焦时优先保留输入与发送，失焦/收键盘恢复完整布局。新增新对话和已有对话的布局回归，并在真实系统镜像软键盘上核验。

## Android 系统与构建

compileSdk/targetSdk 升为 37；AGP 9.2.1、Gradle 9.4.1、JDK 21。Capacitor 8 库仍使用 legacy DSL，因此明确设置 android.newDsl=false。应用维持 minSdk 24，当前审查目标为 API 29–37。

核对 [Android 17 所有应用变化](https://developer.android.com/about/versions/17/behavior-changes-all) 与 [target 37 变化](https://developer.android.com/about/versions/17/behavior-changes-17)：应用不使用小组件、短信、蓝牙或局域网发现；本地页面由 WebView 资源拦截提供，公开 API 使用 HTTPS。重点检查后台音频、内存限制、输入法、边到边布局、文件选择与安装器。

诊断补充页大小、低内存设备标记及退出原因中的 MemoryLimiter 布尔标记，不导出系统退出描述原文。原生 lint 的 NewApi 错误已修复，应用 lint 通过；剩余依赖可更新、图标密度和模板资源等建议不等同于功能通过或失败。

- 本机 Android 10 / WebView 74、Android 15 / WebView 124、Android 17 / WebView 145 的功能验收壳检查通过：聊天准备与模拟 SSE、保留附件的备份恢复、损坏导入保护、完整诊断、取消、文字草稿与显示设置重载、实际软键盘输入及输入框可见、无未捕获 JS 异常。
- 同三版本执行 AndroidCompatibilityTest，通过实际打包资源启动、标准 API、Diagnostics/MicPermission 原生桥、非法更新 URL 拒绝、非法保存参数拒绝等检查。Android 17 运行页大小为 16,384 字节。

- 本地脚本 scripts/android-compat-check.mjs 与工作流 Android 10-17 compatibility 可复用。最终云端矩阵与正式包升级结果见下文。

本机证据：tmp/android17-review（不入库）。测试仅使用模拟 API 响应与人工验收数据，不等同于真实付费 1M 请求、所有网络环境、长期低内存压力或所有品牌物理设备验收。
