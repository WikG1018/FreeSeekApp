# FreeSeek 输入框与模型切换评审

打开同目录的 [交互设计稿](index.html)，可以离线试写、切换模型、添加示例附件和模拟发送。两套草稿各自保留。手机上可以用页面顶部的 A、B 按钮切换方案。

| | A · 拇指旁切换 | B · 顶栏切换 |
| --- | --- | --- |
| 入口 | 输入框左上方显示当前模型，列表向上展开 | 对话标题下显示当前模型，点标题从顶栏向下展开 |
| 适合 | 写到一半，经常需要换模型 | 以阅读长对话为主，偶尔切换模型 |
| 取舍 | 开启开关后，输入区上方多占一行 | 输入框周围更干净，单手切换要够到屏幕上方 |

建议先试 A。写半句，把光标移到句子中间，然后切到 V4 Pro 接着写。再打开模拟键盘，换到 B，比较两种位置的手指移动距离。[浅色对照](composer-comparison.png) · [深色与键盘对照](composer-keyboard.png)

## 两套方案共用的交互

- 空输入框保持单行，随草稿增长，四行后在框内滚动。左侧保留添加入口，右侧根据当前操作显示语音、发送或停止。
- 模型直接按官方服务与已配置服务分组。点选即生效，草稿、光标和附件保留。较长的模型名在列表里完整换行，入口里省略。
- 打开“多模型列表”可以试筛选。草稿已附图片时，纯文本模型会显示不可选的原因。生成期间可以停止回复，完成后恢复切换。
- 模型列表在键盘以上展开。模型入口、模型列表项及发送按钮的触控高度至少 44 像素，系统开启减少动态效果时省略位移。
- 原型里的消息、语音文本和附件均为本地示例，可直接体验发送与停止。

## 已在应用中调整的界面

| 位置 | 展开与返回 |
| --- | --- |
| 设置 | 手机以完整、不透明的页面滑入和退出。进出途中反向操作时从当前位置折返。返回上级保留原来的滚动位置 |
| 人设、附件、API 选项、对话更多 | 菜单贴近触发控件。短列表按内容取高，长选择列表可滚动，超过八项提供筛选。系统返回和 Esc 先收起当前菜单 |
| 搜索来源 | 手机上按资料条数展开底部面板，长列表在面板内滚动。宽屏使用侧边阅读区 |
| 打赏开发者 | 侧边栏使用暖色心形按钮。打赏面板把渠道切换放在二维码前面，选择支付渠道后可以手动保存收款码并打开应用 |
| API 教程、用量明细与数据导入 | 教程保留在 API 页顶部，高级自定义位于页面底部。用量明细就地展开。导入覆盖和删除继续使用单独确认 |
