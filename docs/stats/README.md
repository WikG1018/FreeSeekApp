## 说明

- 统计的是 **Release 资源下载次数**，不是用户数：重装、换机、镜像下载都不计入。
- GitHub 会过滤部分重复请求，数字偏保守；反代镜像的下载完全统计不到。
- 想要真实的活跃用户数，需要 App 内匿名心跳 + 一个后端，这个仓库目前**没有**做。
